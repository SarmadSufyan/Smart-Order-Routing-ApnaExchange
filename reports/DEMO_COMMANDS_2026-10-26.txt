8. IF SOMETHING GOES WRONG
---------------------------
tunnel dies / "connection refused" on 28000      -> Ctrl+C window 2, run the tunnel command again
5190 page says "Connecting..." forever           -> the tunnel (window 2) is down; see above
an exchange shows "trading off" on the real screen -> deploy.py status: the key check line says why; it re-checks every 10 min
the real order is refused "venues can fund X of Y" -> balances: check-keys; the sweep needs both exchanges funded
OKX missing on the laptop                          -> Windows Settings -> Network -> DNS over HTTPS on (1.1.1.1), then  ipconfig /flushdns
real-money screen shows "Sandbox" anywhere        -> you are on :5173 (the laptop), not :5190
