# Simulated venues (historical)

> **Historical (June 2026 prototype).** Five simulated stock venues (FastAPI apps with order books, fill and latency models) that the first prototype routed to. In July 2026 the project moved to real crypto exchanges (`backend/exchanges/`); nothing in the running system uses this folder. Kept as the record of milestone M1.

Run them (optional, for the record): `python venues/start_all_venues.py`.
